# 当前前端口径 · CB-CONFLICT-3.0

M2统一为地缘政治冲突损坏数字依赖后传导至企业服务的中断损失。技术准入、服务商退出、停供过渡不再作为当前M2责任路径。M1不变。

核赔仅保留材料接收与核验、赔款计算、结案材料。回放嵌入材料区，不再逐项勾选；不生成虚假的“人工已核验”标记。材料仍显示实际接收状态。中断时间和恢复时间集中至顶部时间格。责任分类由客户选择的事故原因映射；有效时段、净损失与限额继续约束计算。

九个情景各200,000年，移除准入事件生成，保留原冲突频率、共享事件、再保合同和财务参数，完整重算组合损失与资本分配。典型客户基准年保费USD 4,567.84。运行 python3 scripts/build-conflict-pricing.py 可复现。缓存结果位于data/conflict-pricing/计算。修改参数后须删除相应结果缓存再运行。

新责任版本EE-CONFLICT-3.0；财务条款结构仍为CB-UNIFIED-2.0，定价版本独立升级。旧版已出单项目归档并保留原始快照，活动工作区建立同名新草稿，未出单报价作废重新计算。旧报告PDF不覆盖；当前页面链接到新的定价方法说明。

仅本地更新，未部署服务器或推送GitHub。

## 演示流程精简（2026-11-18）

投保声明、授权财务声明、声明人、收款账户填写和逐项材料提供勾选已从页面与导出文档移除。声明及客户接受字段不再作为阻断条件，也不会自动写成已同意。材料状态根据事故报告中的实际输入及已有材料显示。

提交事故直接进入材料页；核定赔款直接生成核定结果；支付并结案直接扣减本地年度额度。取消这三处重复确认弹窗及客户账户确认步骤。保留无效数据检查、净损失与限额计算、已支付案件重复入账保护。模型版本保存也直接生效，取消审批确认弹窗。
