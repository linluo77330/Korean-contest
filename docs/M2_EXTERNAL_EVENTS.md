# M2 · 外部事件中断 / External Event Disruption

2026-11-18 · coverage EE-2.0 · pricing CP-3.0

本次保留五个工作台、M1/M2两个责任模块、三层风险视图和四层定价。M2不另设子模块或子保费。

## 核保与核赔

- 新问卷记录使用地区、合同主体、关键上游和服务准入辖区；记录已公告限制、迁移时长、替代使用资格、容量、演练及共享上游。
- 既有已确认保单与报价快照不扩展责任。EE-2.0只赋予未出单问卷与新样例；原版M2仍按物理外溢条件审查。
- 外部事件包括列明的第三国物理外溢、强制连接限制及技术服务准入变化，须有事件证据、服务依赖和实际不可用的因果关系。不是所有外部原因均承保。
- 准入变化演示要求公告在保险期间内且非投保前已知；公告与生效日期分离，不赔准备期。实际中断不得早于限制生效，保单到期后不继续累计。
- 业务成功切换到合格替代后停止计时。原有等待期、营业时段、净损失声明、事故及年度限额仍适用。迁移费用、战争/制裁除外及网络事件不因重命名而自动纳入。

样例：11月3日公告；11月17日10:00生效并实际停供；11:50合格替代恢复；原服务18:00恢复。原服务不可用480分钟，实际业务中断110分钟，等待30分钟后可赔80分钟，20,000元/小时对应26,666.67元（未超过32,000元声明净损失）。

## 模型

CP-3.0继续使用20,000个固定种子模拟年度。区域源事件按地区共享；准入事件按服务准入辖区共享，可跨部署区域同时影响客户。每个共同事件在客户层合并服务金额，再用一次事故限额；M1/M2共用年度总限额。

只有备用演练、使用资格、容量和独立上游均通过时，才缩短有效中断。普通/区域依赖事件用RTO；准入变化用`max(迁移适配时长 − 准备期, 0)`，并与原服务中断时长取较小值。再应用等待期、保险期间与营业日历。

新增默认输入：准入事件年概率1.5%、准备期24小时，均为演示情景，不来自公告频率统计。单次准入情景原服务时长为24/72/168小时，权重55%/30%/15%。使用同一辖区的列明服务在该情景中共同受影响，是简化的集中风险假设，不是对所有辖区用户实际影响范围的推断。

保费：`G = (EL + RC + cK + F) / (1 − e)`。现有再保险与资本分摊保持；已纳入营业日历和替代恢复。真实净损失无法在报价时获知，仍作为核赔阶段上限，模型不声称完成真实损失校准。
