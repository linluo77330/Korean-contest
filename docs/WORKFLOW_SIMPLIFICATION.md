# 现场演示流程简化

2026-11-18：按用户要求移除核保人工复核页及逐项复核勾选。核保页保留风险总览、定价明细、报价与保单。提交问卷进入定价明细；“生成保单”直接保存报价、模型和保障条件快照并进入保单页，不再弹出报价确认和保障确认两层窗口。

基本字段、OLA有效范围和现行模型可报价性仍由现有规则校验，避免生成空金额或与客户条件不符的保单。不会自动伪造人工复核记录或客户确认；业务轨迹记录为系统生成保单。重复点击已生成保单只打开原保单。报案编号与生成的保单编号保持一致。

日常页面使用业务操作名称，移除重复模拟标签和防御性说明。研究数据与定价依据保留在数据来源、模型详情、关于和精算报告中。无真实出单、付款或外部服务接口。浏览器已有项目及归档不重置。
