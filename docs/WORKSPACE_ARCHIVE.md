# 演示工作区与归档

2026-11-18 按用户要求清空旧业务记录。首次打开本版本使用空白业务工作区，不自动生成样例投保单。旧的 cloudbridge-workspace-v1 与 cloudbridge-workspace-unified-v2 存储项（含其内嵌归档）被删除。新记录保存在 cloudbridge-workspace-demo-v3，后续刷新不会重置。语言偏好及公开事件数据保留。

- 左上角新建投保单，从企业名称开始；默认 AI API 配置仍可调整。
- 顶部“归档当前项目”移出当前项目列表，左侧“项目归档”集中管理。
- 归档保留完整投保信息、报价、保单快照、赔案、支付台账和操作轨迹。归档本身不会取消保单或改变赔付状态。
- 归档支持只读查看、下载 JSON 和恢复。恢复沿用原编号及原内容，不另建保单。
- 同源新版本标签页同步业务状态；旧版本标签页请刷新后使用。
- 记录仍保存在浏览器中，跨设备移交请导出业务档案；本次未增加云端存储或导入功能。

验证：tests/workspace-archive-browser.test.cjs 覆盖旧存储清理、空状态导航、新建保存、归档与恢复、导出内容、已确认保单及赔案不变、多标签页同步与四种语言布局。
